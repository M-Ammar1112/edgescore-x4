# TinyML demonstrations

No Python runtime or training dependency is part of the bootstrap.

## Demo A: linear INT8 classifier

An approximately eight-feature machine-vibration normal/fault classifier will
eventually use two `ESX.DOT4` operations, a bias, and a threshold.

## Demo B: nearest-centroid anomaly detector

An approximately eight-feature INT8 detector will eventually use two `ESX.SAD4`
operations and a threshold. Training and export scripts will be added later.
