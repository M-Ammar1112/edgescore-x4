# Roadmap

- **M0 - Repository bootstrap:** project structure, build, model, tests, and lint complete.
- **M1 - C++ architectural model:** stabilize model API and vectors.
- **M2 - DOT4 RTL:** implement and verify the DOT4 datapath.
- **M3 - SAD4 RTL:** implement and verify the SAD4 datapath.
- **M4 - PCPI integration:** decode and complete custom instructions.
- **M5 - UVM + DPI scoreboard:** add constrained stimulus and coverage.
- **M6 - PicoRV32 assembly tests:** execute directed instruction tests.
- **M7 - C firmware:** validate the custom-instruction API.
- **M8 - TinyML demos:** add the two small INT8 applications.
- **M9 - Synthesis/benchmarking:** measure area, timing, and performance.
- **M10 - v1.0 release:** freeze and package the IP.
